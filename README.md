# Genetik-Lernlabor

Interaktive Biologie-Lernapp (Genetik) auf Grundlage der PDF „Bio_Genetik“.
Die vollständige Inhaltsanalyse der PDF steht in [`docs/ANALYSE.md`](docs/ANALYSE.md).

> Die App wird in 10 Phasen entwickelt. Diese README wird am Ende vervollständigt.

## Schnellstart

```bash
npm install
npm run dev        # Entwicklungsserver auf http://localhost:5173
npm test           # Unit-Tests (Vitest)
npm run test:e2e   # Klicktests (Playwright) auf Desktop-, Tablet- und Handybreite
```
